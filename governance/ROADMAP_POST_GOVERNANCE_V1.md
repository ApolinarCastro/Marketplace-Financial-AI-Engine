# ROADMAP OFICIAL DE EJECUCIÓN — FASE POST CONSOLIDACIÓN

# 1. PROPÓSITO

Finalizada la consolidación de la gobernanza, el proyecto cambia oficialmente de una fase documental a una fase de ejecución técnica.

A partir de este roadmap, toda actividad deberá generar valor funcional, evidencia técnica o mejoras medibles del producto.

---

# 2. ORDEN DE EJECUCIÓN SECUENCIAL

## ETAPA 1 — REPOSITORY CLEANUP
- **Objetivo:** Verificar que el repositorio contiene únicamente información útil y permanente.
- **Entregables:** Inventario del repositorio, reporte de limpieza, evidencia reproducible, estado final del repositorio.
- **Criterio de Aprobación:** Repositorio limpio, coherente y sin deuda documental ni técnica.

## ETAPA 2 — CHECK XML FILES
- **Objetivo:** Certificar funcionalmente todos los XML utilizados por el sistema.
- **Validaciones:** Estructura XML, esquemas, contratos, campos obligatorios, versiones, marketplace de origen, tipo DTE, consistencia documental, integridad y trazabilidad.
- **Entregables:** Reporte de validación, clasificación de excepciones, XML certificados.

## ETAPA 3 — CHECK RAW XML
- **Objetivo:** Garantizar la integridad absoluta de la capa RAW.
- **Restricción:** Capa RAW inmutable (`RAW_MUTATIONS = 0`).
- **Entregables:** Reporte de integridad, hashes, evidencia.

## ETAPA 4 — CONTINUIDAD DEL ROADMAP FUNCIONAL
- **Objetivo:** Retomar el desarrollo del producto.
- **Prioridades:** Financial Engine, Evidence Registry, Financial Copilot, Dashboard, Marketplace APIs, Motor de conciliación, Dual Graph, KnowledgeOS, Rendimiento, Seguridad, Escalabilidad.

## ETAPA 5 — CONSTRUCCIÓN DE VALOR
- **Objetivo:** Desarrollar únicamente funcionalidades que aporten valor real al usuario.

# 3. REGLAS OFICIALES Y PRINCIPIOS DE EJECUCIÓN

1. **PRINCIPIO DE VALOR TÉCNICO:** Toda actividad debe aportar valor técnico demostrable.
2. **PRINCIPIO DE CONSOLIDACIÓN:** Si un documento no incorpora conocimiento nuevo, no se crea; se consolida.
3. **PRINCIPIO DE SIMPLICIDAD:** Preferir soluciones simples, reproducibles y mantenibles.
4. **PRINCIPIO DE EVIDENCIA:** Evidencia reproducible previa a cualquier afirmación.
5. **PRINCIPIO DE PROTECCIÓN DEL REPOSITORIO:** Repositorio lean con código vivo, datos oficiales, evidencias certificadas y conocimiento permanente.
