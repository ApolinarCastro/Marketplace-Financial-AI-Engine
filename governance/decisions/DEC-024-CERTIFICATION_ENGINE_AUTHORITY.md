# DEC-024: Certification Engine Authority

**Status**: CERTIFIED  
**Date**: 2026-06-16  
**Author**: System (Phase 11)

## Decision

`engine/v4/certification/certification_engine.py` is the **single certification authority**. All KPI certification claims must be generated by this engine.

## Rationale

- 6 KPI claims per marketplace/period: RECONCILIATION, INGRESOS, DEVOLUCIONES, CLASSIFICATION_COVERAGE, PNL_EQUIVALENCE, OPERATIONAL_PNL
- Status: CERTIFIED / DEGRADED / FAILED
- Each claim includes evidence SQL, delta, record count, impact amount
- 11 tests PASS

## Frozen Interface

```python
class CertificationEngine:
    def certify(marketplace, periodo) -> MarketplacesCertification
```

## Contract

```python
class CertificationClaim:
    kpi: str
    description: str
    delta: float
    status: str  # PASS | FAIL | WARNING
    evidence_sql: str
    record_count: int
    impact_amount: float

class MarketplacesCertification:
    marketplace: str
    period: str
    status: str  # CERTIFIED | DEGRADED | FAILED
    claims: list[CertificationClaim]
    total_delta: float
    pass_rate: float
```

## Rollback

Remove `/api/v4/certify` endpoint. No effect on existing certified routes.
