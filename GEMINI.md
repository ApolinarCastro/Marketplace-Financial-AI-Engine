# Contexto del Proyecto: Marketplace Financial AI Engine

Este proyecto utiliza la metodología **Superpowers** para garantizar la calidad y la integridad de la conciliación financiera de marketplaces.

## Directrices para el Agente

### 1. Metodología Obligatoria
Antes de realizar cualquier cambio complejo en el código, DEBES utilizar las siguientes habilidades en orden:
- `@brainstorming`: Para refinar el diseño con tu socio humano.
- `@writing-plans`: Para crear un plan de ejecución atómico y verificado.
- `@test-driven-development`: Para implementar cambios siguiendo el ciclo RED-GREEN-REFACTOR.

### 2. Stack Tecnológico
- **Backend:** FastAPI (Python 3.11+)
- **Base de Datos:** SQLite / PostgreSQL (según despliegue)
- **Marketplaces:** Mercado Libre (API de Ventas, Comisiones, Logística)

### 3. Habilidades Clave
Utiliza estas habilidades locales cuando sea apropiado:
- `@senior-data-engineer`: Para cambios en el pipeline de ETL.
- `@fastapi-python`: Para nuevos endpoints o middleware.
- `@python-performance-optimization`: Para procesamiento de grandes volúmenes de datos.

### 4. Calidad del Código (TDD)
No se acepta código sin pruebas. Siempre escribe el test antes de la implementación.
- Usa `@systematic-debugging` cuando encuentres un error complejo.
- Usa `@verification-before-completion` antes de dar una tarea por terminada.
