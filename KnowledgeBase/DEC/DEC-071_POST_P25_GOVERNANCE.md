# DEC-071 — POST P25 GOVERNANCE

**STATUS**: APPROVED

La etapa de estabilización, limpieza y consolidación de conocimiento ha concluido con la fase P25. La plataforma entra oficialmente en **ENTERPRISE MAINTENANCE MODE**.

## Principios
1. **Evolución por Capacidades**: El crecimiento debe enfocarse en extensión (Marketplace Coverage, Document Intelligence, Operational Intelligence, Forecast, Expansion).
2. **Inmutabilidad del Core**: Prohibido alterar la Baseline V4.
3. **Reuse First**: Está prohibido crear componentes nuevos si existe uno reutilizable (Endpoint, ETL, Motor, Knowledge).
4. **Impact Analysis Gate**: Todo nuevo código debe precederse por Impact Analysis -> Knowledge Graph Query -> Reuse Matrix -> RFC/DEC.
5. **Métricas Permanentes**: 0 archivos UNKNOWN, 0 lógica duplicada, 0 pipelines paralelos, 100% Single Financial Truth, 100% Single Knowledge Truth.

*Cualquier intento de limpieza masiva o refactorización destructiva está prohibido a partir de este punto.*
