# RIPLEY PROMOTIONAL MODEL VALIDATION

**NANDA SPA -> Comercial ECCSA (Factura Tipo 33)**
- **Origen**: Descuentos ofrecidos a cliente final asimilados por la plataforma.
- **Destino**: NANDA cobra a ECCSA la compensación.
- **Impacto Financiero**: Recuperación / Ingreso.
- **Impacto Tributario**: Débito Fiscal para NANDA, Crédito para ECCSA.
- **Impacto Contable**: Aumento cuenta por cobrar / ingreso caja.

**ECCSA -> NANDA (Nota Crédito 61)**
- **Origen**: Reverso de comisiones cobradas indebidamente.
- **Destino**: ECCSA reintegra a NANDA.
- **Impacto**: Anulación parcial del gasto (costos_comerciales).
