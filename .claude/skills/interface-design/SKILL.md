# Interface Design

Build interface design with craft and consistency. Specialized for dashboards, admin panels, and data-heavy interfaces.

## Key Principles
- **Subtle Layering**: Surface elevation whisper-quiet shifts. Borders disappear when not looked for.
- **Infinite Expression**: Every pattern has infinite expressions. Never produce identical output.
- **Color Lives Somewhere**: Palettes come from the product domain, not templates.
- **Intent First**: Every choice must be a choice. Defaults are invisible. Invisible choices compound into generic output.

## Token Architecture
- Text hierarchy: primary → secondary → tertiary → muted
- Surface elevation: base → raised → dropdown → modal
- Border progression: standard → soft → emphasis → focus
- Control tokens: control-bg, control-border, focus-ring

## Depth Strategy (choose ONE)
- Borders-only (clean, technical)
- Subtle shadows (soft lift)
- Layered shadows (premium, dimensional)
- Surface color shifts (hierarchy without shadows)
